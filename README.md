# NEXS — فريق تداول من وكلاء الذكاء الاصطناعي

مدير تنفيذي (Claude) يدير فريقاً من الوكلاء، كل وكيل له مهمة. يتصل الفريق بـ Interactive Brokers أو بمحاكي مدمج. تعرض لوحة تحكم بالعربي الوكلاء وهم يرسلون لبعض لحظة بلحظة، وتقدر تعدّل أي شيء والنظام شغّال.

## الفريق

| الوكيل | مهمته | العقل |
|---|---|---|
| المدير التنفيذي | يجمع تقارير الجميع ويقرر: شراء / بيع / انتظار | Claude |
| الماسح | يختار الأسهم الأنشط من قائمة المراقبة | قواعد |
| المحلل الفني | الاتجاه والزخم و RSI | قواعد (سريع ومجاني) |
| محلل الأخبار | يقرأ العناوين ويقيّم أثرها | Claude |
| محلل السوق العام | مزاج السوق من SPY و QQQ | Claude |
| محلل الأساسيات | التقييم والنمو وإجماع المحللين وسعرهم المستهدف (Yahoo Finance)، مرة كل ساعة | Claude |
| المتفائل | يبني أقوى حجة للشراء في أهم سهمين قبل كل قرار | Claude |
| المتشائم | يبني أقوى حجة ضد الصفقة ويكشف المخاطر | Claude |
| مدير المخاطر | حدود صارمة بالكود، ولا يستطيع أي وكيل تجاوزها | قواعد |
| المنفّذ | يرسل الأوامر مع وقف خسارة وجني أرباح إلزاميين | قواعد |
| المدقق | يقيّم كل إشارة، ويوزّع المكافآت، ويكتب درساً من كل صفقة للمدير | Claude + قواعد |

تقدر توظّف وكلاء جدد من الواجهة (تبويب «الإعدادات والوكلاء») بدون أي برمجة: تكتب له التعليمات، فيصير يحلل ويرسل إشاراته للمدير التنفيذي.

## النقاش والتعلّم (مأخوذة من TradingAgents)

- **النقاش قبل القرار:** قبل أن يقرر المدير التنفيذي، يناقش المتفائل والمتشائم أقوى سهمين في الدورة، ويصل النقاش للمدير مع إشارات المحللين. يُطلب من المدير أن يحسم لصالح الحجة الأقوى بدل الانتظار كلما تعارضت الآراء.
- **الدروس من الصفقات:** بعد ما تتضح نتيجة كل قرار، يكتب المدقق درساً قصيراً (هل كان القرار صحيحاً ولماذا). آخر ٦ دروس تُرسل للمدير التنفيذي في كل دورة، عشان ما يكرر نفس الأخطاء.
- **مدة التقييم:** إشارات محلل الأساسيات تُقيَّم بعد يوم كامل، لأن أثرها أبطأ. باقي الوكلاء بعد ٥ دقائق. تقدر تغيّر المدة لكل وكيل من `horizon` في `config/agents.yaml`.

الأفكار مأخوذة من مشروع [TradingAgents](https://github.com/TauricResearch/TradingAgents) (رخصة Apache-2.0)، ومكتوبة من جديد لتناسب التداول السريع.

## المكافآت

كل إشارة يرسلها أي وكيل تُسجَّل. بعد ٥ دقائق يقارن المدقق اتجاهها بحركة السعر الفعلية:
- **إشارة صحيحة:** يكسب الوكيل نقاطاً.
- **إشارة خاطئة:** يخسر نقاطاً.

بعد ١٠ إشارات مُقيّمة يتعدّل **وزن الوكيل عند المدير التنفيذي** تلقائياً، من ×٠٫٢٥ للأسوأ حتى ×٢ للأفضل. يعني الوكيل المتميز يصير صوته أعلى. الترتيب في تبويب «الترتيب والمكافآت».

## التشغيل

```bash
pip install -r requirements.txt
cp .env.example .env      # ضع ANTHROPIC_API_KEY
./run.sh                  # يعيد التشغيل تلقائياً إذا توقف (على ويندوز: run.bat)
```

افتح http://127.0.0.1:8000

- **بدون مفتاح Claude:** يعمل كل شيء بالقواعد البرمجية، فتقدر تجرّب الواجهة فوراً.
- **بدون IBKR:** يعمل على المحاكي (`NEXS_BROKER=sim`)، بأسعار عشوائية واقعية وأخبار وهمية.

## الربط مع IBKR

1. ثبّت **IB Gateway** أو **TWS**، وسجّل الدخول بحساب **Paper Trading** (التجريبي).
2. من الإعدادات، افتح API → Settings وفعّل:
   - `Enable ActiveX and Socket Clients`
   - المنفذ `4002` لـ IB Gateway التجريبي، أو `7497` لـ TWS التجريبي.
   - ألغِ `Read-Only API`.
3. في ملف `.env` ضع `NEXS_BROKER=ibkr` ثم شغّل.

يتعرف النظام تلقائياً على نوع الحساب. **أي حساب حقيقي يُرفض إرسال الأوامر عليه** إلا إذا وضعت `NEXS_ALLOW_LIVE=1` بنفسك. ابدأ بالتجريبي أسابيع قبل التفكير في الحقيقي.

## التعديل وهو شغّال

- **من الواجهة:** اضغط على أي وكيل لتعديل تعليماته ونموذجه وعمق تفكيره ووزنه، أو لإيقافه. وتقدر أيضاً تعدّل حدود المخاطر والأسهم المراقبة وسرعة الدورة، وتوظّف وكلاء جدد. كل تعديل يسري من الدورة التالية.
- **من الملفات:** `config/agents.yaml` و `config/risk.yaml` تُقرأ من جديد كل دورة.
- **التوجيهات:** اكتب للمدير التنفيذي مباشرة، مثل «لا تفتح صفقات على TSLA اليوم».
- **زر إيقاف التداول:** يوقف الأوامر الجديدة فوراً، مع خيار إغلاق كل المراكز.
- **تعديل الكود نفسه** (إضافة نوع جديد من الوكلاء مثلاً) يحتاج إعادة تشغيل، و `run.sh` يعيد التشغيل تلقائياً.

## الأمان

- **حد الخسارة اليومية:** عند الوصول له يتوقف التداول تلقائياً.
- **وقف الخسارة:** إلزامي لكل صفقة، ويُرسل لـ IBKR كأمر مرتبط (bracket) فيُنفَّذ عندهم حتى لو توقف النظام.
- **حدود الصفقات:** حد لقيمة كل مركز، ولمجموع المراكز، ولعدد الأوامر بالساعة.
- **حماية الواجهة:** تعمل على جهازك فقط افتراضياً. إذا فتحتها للإنترنت فضع `NEXS_TOKEN`.

## ملاحظات صريحة

- **السرعة:** «التداول السريع» هنا بالثواني والدقائق، وليس تداولاً عالي التردد. قرار Claude يأخذ عدة ثوانٍ، لذلك الدورة الافتراضية ٣٠ ثانية. وقف الخسارة وجني الأرباح يُنفَّذان فوراً عند IBKR.
- **الضمانات:** لا يوجد نظام يضمن الربح. راقب الأداء على الحساب التجريبي واترك حدود المخاطر صارمة.
- **الاستضافة:** للتشغيل ٢٤ ساعة يحتاج النظام جهازاً أو سيرفراً (VPS) شغّالاً دائماً، وعليه IB Gateway. جلسات Claude Code السحابية مؤقتة ولا تصلح لاستضافته.
